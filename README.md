# 📝 Agenda de Tarefas em Python

Um gerenciador de tarefas simples via terminal desenvolvido em Python. Permite adicionar, listar, concluir, remover e salvar tarefas em um arquivo JSON local para persistência de dados.

## 🚀 Funcionalidades

* ➕ **Adicionar Tarefas:** Insira uma descrição e um prazo opcional (`dd/mm/aaaa`).
* 📋 **Listar Tarefas:** Visualize todas as tarefas cadastradas com status e data de criação.
* ✅ **Concluir Tarefas:** Marque tarefas pendentes como concluídas.
* 💾 **Persistência de Dados:** Salva e carrega as tarefas automaticamente no arquivo `tarefas.json`.

## 🛠️ Tecnologias Utilizadas

* **Python 3**
* **Módulos nativos:** `json`, `os`, `datetime`
